# Dipu Singh — Personal Brand Website

A responsive static website for Dipu Singh, based in Kalyani, West Bengal.

## Files
- `index.html` — website content and SEO metadata
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation and current year
- `images/dipu-singh.jpg` — profile photograph
- `images/certificate.jpg` — certificate preview
- `documents/dipu-singh-certificate.pdf` — original certificate PDF
- `robots.txt` — crawler instructions

## Preview locally
Open `index.html` in a browser. For a closer-to-hosting preview, run a local static server from this folder.

## Upload to hosting
1. Extract the ZIP file.
2. Open your hosting file manager.
3. Open the website document root (often `public_html`).
4. Upload the *contents* of the `dipu-singh-website` folder, not the parent folder.
5. Confirm `index.html` is directly inside the document root.
6. Open the domain and test WhatsApp, call, certificate and map links.

## Before launch
- Connect your own domain and enable HTTPS.
- Keep the address and phone details consistent with your public business listings.
- Add the final domain to Google Search Console and submit `/sitemap.xml` once a domain is selected.
- This website does not promise Google ranking; indexing and local visibility depend on Google and consistent public business information.
